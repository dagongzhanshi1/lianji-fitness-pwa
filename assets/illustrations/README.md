# 337 张统一风格动作图

练迹为 334 个预置动作，以及「宽握对握高位下拉」「下胸飞鸟」「杠铃提拉」3 个补充动作提供 337 张独立图片。图片由 AI 图像生成工具制作，随本仓库一起提供，约 37.1 MiB。

## 风格与动作区别

统一使用灰色无面部训练模型、深灰短裤、白色背景和暗红色主要发力肌群。图片覆盖胸、背、肩、手臂、腿、臀、腹部与核心、全身与功能性、有氧九大类。

正握、反握、中立握、宽握和窄握等已收录的变式分别配图；器械、自由重量、单侧与双侧变式也按动作名称区分。部分握法复杂的图带有手部特写。

制作时逐张检查姿势、握法、器械结构和风格。图片是用于识别动作与参考关键姿势的**静态示意图**，不能展示完整动作过程。若发现错误，请附上动作名称和具体问题提交 Issue。

## 文件与复用

| 文件 | 内容 |

| [`../../docs/exercise-media/`](../../docs/exercise-media/) | 337 张最终 JPG，每张最长边 900 px |

图片文件名包含动作 ID 和内容哈希。替换图片时使用新哈希文件名，避免旧缓存继续显示旧图。图片没有重复存放在这个说明目录中，原文件统一位于 `docs/exercise-media/`。

本仓库代码、提示词和项目自制图片按根目录 [MIT 许可证](../../LICENSE) 提供。图像由 AI 生成，不是实拍照片。生成过程曾使用公开动作资料核对姿势；这些外部原始照片或 GIF 不包含在本仓库里，相关链接不属于本项目的许可范围。

提示词中的“参考图 1”指统一视觉风格，“参考图 2”指动作姿势或器械参考。再次生成时需要自行准备对应参考；可使用本仓库现有合格图片作为风格参考。生成结果具有随机性，仅使用同一段提示词不能保证复现相同画面。

## App 中如何使用

1. 选择动作：用紧凑的小图列表识别动作，点缩略图放大。
2. 记录训练：动作旁展示配图和历史最大重量；新训练从一组空白数据开始。
3. 查看历史：每个动作配有缩略图，可放大后返回原记录。
4. 离线使用：首次查看后缓存该图；在设置点击“下载整套动作图”可一次缓存全部，下载失败后保留已有进度，再次点击可继续。

已收录图片直接从本仓库同源加载，运行时不需要访问外部动作图库或图像生成服务。新建但尚未配图的自定义动作会显示“暂无准确示范”，不会自动套用其他动作的图片。
